# Referencia visual de legislación

`public-codigo-civil-articulo-1.png` se capturó antes de extraer el renderizador compartido, en `http://127.0.0.1:3103/legislacion/codigo-civil?art=1`, con un viewport de 988 × 712 px.

`public-codigo-civil-articulo-1-shared-renderer.png` se capturó después de activar `legal-visual-renderer.js`, con el mismo viewport y el artículo alineado en la misma posición.

Ambas imágenes deben conservar el mismo SHA-256. Esto protege la apariencia pública existente frente a cambios accidentales del renderizador compartido.

`admin-legislation-converter-integration.png` documenta la integración aislada del editor jurídico original dentro del administrador, con la barra completa y el botón `PUBLICAR CAMBIOS`.
